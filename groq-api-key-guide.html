Як отримати Groq API ключ

Groq пропонує безкоштовний доступ до надшвидкого LLM-інференсу. Цей гайд проведе вас від реєстрації до першого запиту за 5 хвилин.

⏱ Час: ~5 хвилин
💳 Без картки: безкоштовний план
🌍 Мова сайту: Англійська
⚡

Що таке Groq і навіщо потрібен API ключ?

Groq — хмарна платформа з власними LPU-чипами (Language Processing Unit), яка забезпечує один з найшвидших у світі LLM-інференсів. API ключ — ваш особистий токен доступу для відправки запитів до моделей (Llama, Mixtral, Gemma та ін.) з коду або інструментів.

Покрокова інструкція

01
Перейдіть на сайт Groq
Відкрийте консоль розробника
🌐

Відкрийте браузер і перейдіть за посиланням нижче. Це консоль Groq — місце, де керуються API ключі та статистика використання.

https://console.groq.com

Також можна зайти через groq.com → кнопка "Start Building" або "Login" у правому верхньому куті.

02
Створіть акаунт або увійдіть
Реєстрація через Google, GitHub або email
👤

На сторінці входу оберіть зручний спосіб реєстрації:

Google — найшвидший варіант, якщо маєте Google-акаунт.
GitHub — зручно для розробників.
Email + пароль — класичний варіант, потребує підтвердження email.

Groq не вимагає кредитної картки для безкоштовного плану. Просто оберіть вхід через Google або GitHub — і за секунди ви в системі.

03
Підтвердіть email (якщо потрібно)
Тільки при реєстрації через email
📧

Якщо ви обрали реєстрацію через email, на вашу пошту надійде лист від Groq з посиланням для підтвердження. Перейдіть за ним — і ваш акаунт буде активовано.

При вході через Google або GitHub цей крок пропускається автоматично.

04
Перейдіть до розділу API Keys
Знайдіть розділ керування ключами
🔑

Після входу знайдіть у лівому бічному меню пункт "API Keys" і натисніть на нього.

Або перейдіть напряму за посиланням:

https://console.groq.com/keys

Якщо ви щойно зареєструвались, на сторінці буде порожньо — це нормально, зараз ми створимо перший ключ.

05
Створіть новий API ключ
Натисніть кнопку та задайте назву
✨

Натисніть "Create API Key" (або "+ Create"). У діалозі введіть зрозумілу назву: my-app, test-project або personal. Назва — лише для вашої зручності.

Після введення натисніть "Submit" або "Create".

Ключ буде показано один раз. Скопіюйте його негайно — після закриття вікна він більше не відображатиметься!

06
Збережіть ключ у безпечному місці
Нікому не передавайте та не публікуйте
🔒

Ключ виглядає приблизно так: gsk_xxxxxxxxxxxxxxxxxxxx. Збережіть його у надійному місці:

Рекомендовані варіанти:
• Менеджер паролів (Bitwarden, 1Password, KeePass)
• Файл .env у проєкті (додайте до .gitignore!)
• Змінна середовища GROQ_API_KEY в операційній системі

Ніколи не зберігайте ключ прямо в коді та не публікуйте його на GitHub або Pastebin. Якщо ключ скомпрометовано — видаліть його в консолі та створіть новий.

Поширені питання

Де подивитись ліміти безкоштовного плану?
Актуальні ліміти (RPM, RPD, TPM) — на сторінці console.groq.com/settings/limits або в офіційній документації Rate Limits.
Чи можна мати кілька API ключів?
Так. Ви можете створити кілька ключів для різних проєктів. Якщо один скомпрометовано — видаліть лише його, не торкаючись інших.
Groq API сумісний з OpenAI API?
Так! Змініть base_url на https://api.groq.com/openai/v1 і передайте Groq ключ — ваш OpenAI-сумісний код запрацює без змін.
Що робити, якщо загубив ключ?
Groq не показує ключ повторно. Видаліть старий у консолі та створіть новий — займає менше хвилини.
Чи потрібен VPN для доступу з України?
Наразі Groq доступний з України без VPN. Якщо сайт не завантажується — спробуйте VPN із виходом через США або Євросоюз.

Step-by-Step Guide

How to Get a Groq API Key

Groq offers free access to ultra-fast LLM inference. This guide takes you from sign-up to your first API request in under 5 minutes.

⏱ Time: ~5 minutes
💳 No card: free plan available
🌍 Site language: English
⚡

What is Groq and why do I need an API key?

Groq is a cloud platform built around proprietary LPU (Language Processing Unit) chips that deliver some of the fastest LLM inference in the world. An API key is your personal access token — it lets you send requests to models like Llama, Mixtral, and Gemma from your code or tools.

Step-by-Step Instructions

01
Open the Groq Console
Navigate to the developer dashboard
🌐

Open your browser and go to the link below. This is the Groq Console — the central place for managing API keys and monitoring usage.

https://console.groq.com

You can also reach it from groq.com by clicking "Start Building" or "Login" in the top-right corner.

02
Create an account or sign in
Sign up via Google, GitHub, or email
👤

On the login page, choose your preferred sign-up method:

Google — fastest option if you have a Google account.
GitHub — convenient for developers.
Email + password — classic option, requires email confirmation.

Groq does not require a credit card for the free plan. Click "Continue with Google" or "Continue with GitHub" and you're in within seconds.

03
Confirm your email (if needed)
Only required when signing up with email
📧

If you chose email sign-up, Groq will send you a confirmation link. Click it to activate your account.

If you signed in via Google or GitHub, this step is skipped automatically.

04
Go to the API Keys section
Find the key management panel
🔑

Once logged in, find "API Keys" in the left sidebar and click it.

Or navigate directly to:

https://console.groq.com/keys

If you just registered, the page will be empty — that's expected. You're about to create your first key.

05
Create a new API key
Click the button and give it a name
✨

Click "Create API Key" (or "+ Create"). A dialog will appear — enter a descriptive name like my-app, test-project, or personal. The name is only for your reference.

Then click "Submit" or "Create".

The key will be shown only once. Copy it immediately — after closing the dialog, it will never be displayed again!

06
Store your key securely
Never share or publish it publicly
🔒

Your key looks something like: gsk_xxxxxxxxxxxxxxxxxxxx. Store it in a safe place:

Recommended options:
• A password manager (Bitwarden, 1Password, KeePass)
• A .env file in your project (add it to .gitignore!)
• An environment variable GROQ_API_KEY on your OS

Never hardcode the key in your source code or post it on GitHub or Pastebin. If a key is compromised — delete it in the console and generate a new one.

FAQ

Where can I check the free plan rate limits?
Current limits (RPM, RPD, TPM) are listed at console.groq.com/settings/limits and in the official Rate Limits documentation.
Can I have multiple API keys?
Yes. You can create multiple keys for different projects. If one is compromised — delete only that one, the others remain unaffected.
Is the Groq API compatible with the OpenAI API?
Yes! Just change the base_url to https://api.groq.com/openai/v1 and pass your Groq key — your OpenAI-compatible code will work without further changes.
What if I lost my API key?
Groq does not show the key again after creation. Delete the old key in the console and create a new one — it takes less than a minute.
Are there any geographic restrictions?
Groq is generally accessible worldwide. If you experience access issues, try using a VPN with an exit node in the US or EU.
