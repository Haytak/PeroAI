Як отримати Gemini API ключ

Google Gemini надає безкоштовний доступ до своїх моделей через Google AI Studio. Цей гайд проведе вас від реєстрації до готового ключа за 3 хвилини.

⏱ Час: ~3 хвилини
💳 Без картки: безкоштовний план
🌍 Мова сайту: Англійська
✦

Що таке Gemini API і навіщо потрібен ключ?

Google Gemini API — це офіційний інтерфейс для роботи з мультимодальними моделями Google (Gemini 2.0 Flash, Gemini 1.5 Pro та ін.). API ключ — ваш токен для відправки запитів з коду, скриптів або сторонніх інструментів. Безкоштовний рівень доступний без кредитної картки.

Покрокова інструкція

01
Перейдіть до Google AI Studio
Офіційний портал для розробників
🌐

Відкрийте браузер і перейдіть за посиланням нижче. Це Google AI Studio — офіційна платформа для роботи з Gemini API, де керуються ключі та проводяться тести.

https://aistudio.google.com

Також можна дістатись через офіційну документацію на ai.google.dev → кнопка "Get API key".

02
Увійдіть за допомогою Google-акаунту
Реєстрація окремого акаунту не потрібна
👤

Google AI Studio використовує ваш існуючий Google-акаунт. Натисніть "Sign in" і оберіть потрібний акаунт.

Якщо ви ще не залогінені в Google — введіть email та пароль від вашого Google-акаунту.

Підійде будь-який Google-акаунт: особистий Gmail, корпоративний Google Workspace або навчальний. Кредитна картка на безкоштовному рівні не потрібна.

03
Прийміть умови використання
Тільки при першому вході
📋

При першому вході Google AI Studio може показати вікно з умовами використання (Terms of Service). Прочитайте та натисніть "I agree" або "Continue".

Також може з'явитись вибір країни та підтвердження вікового обмеження. Заповніть та підтвердіть.

Якщо ваш акаунт є шкільним або керованим організацією, адміністратор може заблокувати доступ до AI Studio. У такому випадку використайте особистий Google-акаунт.

04
Натисніть "Get API key"
Знайдіть кнопку в лівому меню або на головній
🔑

У лівому бічному меню знайдіть і натисніть "Get API key". Або перейдіть напряму за посиланням:

https://aistudio.google.com/apikey

На цій сторінці відображаються всі ваші API ключі та проєкти Google Cloud, до яких вони прив'язані.

05
Створіть новий API ключ
Оберіть проєкт або створіть новий
✨

Натисніть кнопку "Create API key". З'явиться діалог із вибором проєкту Google Cloud.

Якщо у вас ще немає проєкту: натисніть "Create API key in new project" — Google автоматично створить новий безкоштовний проєкт.

Якщо вже є проєкт: оберіть його зі списку та натисніть "Create API key in existing project".

Ключ буде згенеровано миттєво та показано у вікні. Натисніть іконку копіювання поруч з ключем або кнопку "Copy".

06
Збережіть ключ у безпечному місці
Нікому не передавайте та не публікуйте
🔒

Ключ виглядає приблизно так: AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXX. Збережіть його надійно:

Рекомендовані варіанти:
• Менеджер паролів (Bitwarden, 1Password, KeePass)
• Файл .env у проєкті (додайте до .gitignore!)
• Змінна середовища GEMINI_API_KEY або GOOGLE_API_KEY в системі

На відміну від Groq, Google AI Studio дозволяє переглянути ключ повторно на сторінці керування. Але все одно рекомендуємо зберігати його окремо та не публікувати в коді.

Поширені питання

Які моделі доступні безкоштовно?
На безкоштовному рівні доступні Gemini 2.0 Flash, Gemini 1.5 Flash, Gemini 1.5 Flash-8B та деякі інші. Актуальний список — на сторінці моделей в документації.
Де переглянути або видалити ключ?
Всі ваші ключі відображаються на сторінці aistudio.google.com/apikey. Там само їх можна скопіювати або видалити.
Gemini API сумісний з OpenAI API?
Так, частково. Google надає OpenAI-сумісний endpoint: змініть base_url на https://generativelanguage.googleapis.com/v1beta/openai/ і передайте ваш Gemini API ключ.
Чи використовуються мої дані для навчання моделей?
На безкоштовному рівні — так, Google може використовувати запити для покращення моделей. На платному рівні (Pay-as-you-go) ваші дані не використовуються для навчання.
Чи потрібен VPN для доступу з України?
Google AI Studio наразі доступний з України без VPN. Якщо виникають проблеми — спробуйте VPN із виходом через США або Євросоюз.

Step-by-Step Guide

How to Get a Gemini API Key

Google Gemini provides free access to its models via Google AI Studio. This guide takes you from sign-in to a ready-to-use API key in under 3 minutes.

⏱ Time: ~3 minutes
💳 No card: free tier available
🌍 Site language: English
✦

What is the Gemini API and why do I need a key?

The Google Gemini API is the official interface for working with Google's multimodal models (Gemini 2.0 Flash, Gemini 1.5 Pro, and more). An API key is your personal access token — it allows you to send requests from code, scripts, or third-party tools. A free tier is available with no credit card required.

Step-by-Step Instructions

01
Go to Google AI Studio
The official developer portal
🌐

Open your browser and navigate to the link below. Google AI Studio is the official platform for working with the Gemini API — it's where you manage keys, run tests, and explore models.

https://aistudio.google.com

You can also get there from the official docs at ai.google.dev by clicking the "Get API key" button.

02
Sign in with your Google account
No separate registration needed
👤

Google AI Studio uses your existing Google account. Click "Sign in" and select the account you want to use.

If you aren't already signed in to Google, enter your Gmail address and password.

Any Google account works: personal Gmail, Google Workspace, or a school account. No credit card is required for the free tier.

03
Accept the Terms of Service
First-time login only
📋

On your first visit, Google AI Studio will display a Terms of Service dialog. Review and click "I agree" or "Continue".

You may also be asked to confirm your country and age. Fill in the fields and proceed.

If your account is managed by a school or organization, the admin may have blocked access to AI Studio. In that case, use a personal Google account instead.

04
Click "Get API key"
Find it in the left sidebar or on the home screen
🔑

In the left sidebar, find and click "Get API key". Or go directly to:

https://aistudio.google.com/apikey

This page shows all your existing API keys and the Google Cloud projects they are linked to.

05
Create a new API key
Choose a project or create a new one
✨

Click "Create API key". A dialog will appear asking you to select a Google Cloud project.

If you have no project yet: click "Create API key in new project" — Google will automatically create a free project for you.

If you already have a project: select it from the list and click "Create API key in existing project".

The key is generated instantly and shown in the dialog. Click the copy icon next to it or press the "Copy" button.

06
Store your key securely
Never share or publish it publicly
🔒

Your key looks something like: AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXX. Store it somewhere safe:

Recommended options:
• A password manager (Bitwarden, 1Password, KeePass)
• A .env file in your project (add to .gitignore!)
• An environment variable GEMINI_API_KEY or GOOGLE_API_KEY on your OS

Unlike Groq, Google AI Studio lets you view your key again later on the management page. Still, treat it like a password — never commit it to source code or post it publicly.

FAQ

Which models are available for free?
The free tier includes Gemini 2.0 Flash, Gemini 1.5 Flash, Gemini 1.5 Flash-8B, and others. See the full current list in the models documentation.
Where can I view or delete my key?
All your keys are listed at aistudio.google.com/apikey. You can copy or delete them there at any time.
Is the Gemini API compatible with the OpenAI API?
Yes, partially. Google provides an OpenAI-compatible endpoint: change base_url to https://generativelanguage.googleapis.com/v1beta/openai/ and pass your Gemini API key.
Will my data be used to train Google's models?
On the free tier — yes, Google may use your prompts to improve models. On the paid tier (Pay-as-you-go), your data is not used for training.
Are there any geographic restrictions?
Google AI Studio is generally available worldwide. If you encounter access issues, try a VPN with an exit node in the US or EU.
